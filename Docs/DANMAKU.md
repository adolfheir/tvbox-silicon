# 播放器弹幕（iPhone / iPadOS 17+、Mac）

播放影片时默认自动按片名与当前集数寻找弹幕，明确匹配到就显示；没有对应弹幕、季度或集数不明确、服务请求失败时均静默不显示，不影响视频播放。iPhone/iPad 轻点画面后选择右上「更多」→「弹幕」，Mac 选择播放器顶栏「弹幕」，即可手动搜索片名并选择季度与集数，或关闭自动匹配。支持滚动、顶部和底部弹幕，并提供显示开关、字号、不透明度、时间偏移以及清除功能；时间偏移为正时会延后显示。暂停、拖动进度和倍速播放均使用 AVPlayer 的媒体时间同步。弹幕层不接收触摸，播放控制仍可使用；iPhone/iPad 弹幕层挂载在 AVKit 的 `contentOverlayView` 内。

也可选择「导入弹幕文件」，从文件 App 导入 Bilibili 格式的 XML 或弹弹play v2 格式的 JSON。文件保留在设备上读取，不会上传，载入后无需联网。每份文件最大 8 MiB、最多读取 30,000 条弹幕；拥挤时会丢弃无法放入轨道的弹幕，画面下方保留字幕空间。高级定位和脚本弹幕暂不支持。切换影片会取消旧的匹配并重新自动寻找；手动选择轨道或导入文件后优先采用该选择。

视频仍来自原有 TVBox 订阅。弹幕是独立的数据轨道，不代表视频源自带弹幕，也不是所有影片都有匹配数据；本版本不发送弹幕。

1.0.4（12）自动匹配同时尝试 Dandanplay 兼容服务与 dmku，优先采用第一个准确匹配且有内容的结果，并取消剩余请求。Dandanplay 默认地址为 [uosc_danmaku 维护的公开兼容接口](https://github.com/Tony15246/uosc_danmaku#api_server) `https://danmaku-api.152468.xyz`；dmku 默认地址为 [`https://dmku.hls.one/`](https://dmku.hls.one/)。App 直接兼容两种响应格式，无需用户部署转换服务。没有对应弹幕或服务失败时，播放器保持静默；弹幕设置页可查看匹配状态、来源及是否使用本地缓存，也可重新匹配。

当原选集地址是受支持的官方单集页面时，直接用于 dmku；否则在用户开启「自动查找官方集数页面」时，通过爱奇艺和腾讯的公开作品信息按片名、年份（已知时）和明确集数查找。预告、花絮、同名多作品或集数歧义不自动选用。直接页面目前接受爱奇艺、腾讯、优酷、芒果和 Bilibili 番剧单集地址，自动搜索范围为爱奇艺和腾讯。请求发送片名、作品/集数 ID 或经过校验的官方公开单集页面，不发送 TVBox 媒体流地址、订阅地址、播放请求头或账号凭据。可以关闭自动查找、自动匹配或弹幕显示。公共服务可用性和限流不由 App 控制；也可填写自己的 [danmu_api](https://github.com/huangxd-/danmu_api) 兼容服务，支持带路径前缀的服务器地址，末尾可带 `/api/v2`。

弹幕按订阅、点播源和剧的身份隔离，当前集缓存 7 天，同集切线路可复用。当前集有弹幕后，低优先级预取下一集一份；切片或停止播放即取消。手动选择或导入也写入当前集缓存。历史中的剧优先保留，删除历史会清理该剧的弹幕、选集缓存、封面及片头片尾时间，并阻止删除前的下载重新写回。成功作品地址映射独立保留最近 20 部、最长 30 天，便于以后快速重新匹配；没有匹配仅缓存 5 分钟，服务失败仅缓存 30 秒，手动重试可绕过。设置中的「本地缓存」可以一次清理全部可再下载内容，历史和偏好保留，详见 [LIBRARY_CACHE.md](LIBRARY_CACHE.md)。

[弹弹play 官方接口](https://doc.dandanplay.com/open/)需要独立申请 AppId/AppSecret。本项目不借用其他应用的密钥；直接填写官方地址可能返回未授权提示。

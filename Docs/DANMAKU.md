# 播放器弹幕（iPhone / iPadOS 17+、Mac）

播放影片时默认自动按片名与当前集数寻找弹幕，明确匹配到就显示；没有对应弹幕、季度或集数不明确、服务请求失败时均静默不显示，不影响视频播放。也可轻点画面，在播放器顶部选择「弹幕」手动搜索片名并选择季度与集数，或关闭自动匹配。支持滚动、顶部和底部弹幕，并提供显示开关、字号、不透明度、时间偏移以及清除功能；时间偏移为正时会延后显示。暂停、拖动进度和倍速播放均使用 AVPlayer 的媒体时间同步。弹幕层不接收触摸，原生播放控制仍可使用；iPhone/iPad 弹幕层挂载在 AVKit 的 `contentOverlayView` 内。

也可选择「导入弹幕文件」，从文件 App 导入 Bilibili 格式的 XML 或弹弹play v2 格式的 JSON。文件保留在设备上读取，不会上传，载入后无需联网。每份文件最大 8 MiB、最多读取 30,000 条弹幕；拥挤时会丢弃无法放入轨道的弹幕，画面下方保留字幕空间。高级定位和脚本弹幕暂不支持。切换影片会取消旧的匹配并重新自动寻找；手动选择轨道或导入文件后优先采用该选择。

视频仍来自原有 TVBox 订阅。弹幕是独立的数据轨道，不代表视频源自带弹幕，也不是所有影片都有匹配数据；本版本不发送弹幕。

默认弹幕服务为 [uosc_danmaku 维护的公开兼容接口](https://github.com/Tony15246/uosc_danmaku#api_server) `https://danmaku-api.152468.xyz`。播放时的自动匹配，以及用户手动搜索和选择集数会访问该服务；发送的是搜索片名、作品 ID 和集数 ID，不发送视频地址、订阅地址或视频请求头。可关闭自动匹配和弹幕显示。服务包含频率限制，不能批量抓取。也可填写自己的 [danmu_api](https://github.com/huangxd-/danmu_api) 兼容服务，支持带路径前缀的服务器地址，末尾可带 `/api/v2`。

[弹弹play 官方接口](https://doc.dandanplay.com/open/)需要独立申请 AppId/AppSecret。本项目不借用其他应用的密钥；直接填写官方地址可能返回未授权提示。

## 验证边界（2026-10-10）

解析、重复弹幕过滤、异常输入、文件大小限制、XML 安全处理、暂停/前后跳转的时间线、轨道拥挤和服务地址处理均有核心测试。Mac 端已实测公共服务能搜索《葬送的芙莉莲》、获取集数并下载第 1 集 7,310 条真实弹幕。前一 1.0.1 组合版在 iPadOS 17.7.11 第六代 iPad 已安装并完成真机复测：在线加载《葬送的芙莉莲》第 1 集 7,310 条弹幕，AVPlayer 连续推进超过 119 秒、rate=1、无播放错误，真机截图确认弹幕位于视频内且字幕区域保留。初次连接公共服务曾超时，复测已成功，后续可用性仍取决于该服务及网络。

隔离 iPad 模拟器（iOS 18.2，强制旧版 UI）的真实网络 UI 验收已通过：搜索片名、选择第 1 集、显示 7,310 条弹幕、关闭和重新开启弹幕、返回播放器均通过，截图已确认弹幕位于视频区域内。模拟器 QA 目标不含 Java 运行时，不能据此判断真机 JAR 源兼容性。测试不应针对用户正在使用的 App 数据容器运行。

最终整合源码的 107 项核心测试、四语 375 个 key 检查及完整 iOS/macOS 构建通过。新增自动匹配的成功、无对应集数、服务失败静默隐藏用例，以及重启后历史续播与片头片尾保存/自动跳过用例均在隔离模拟器通过；本地测试接口不作为真机在线服务可用性证明。1.0.2（5）实体设备用例验证真实影片的历史精确续播，以及无匹配时弹幕为空且视频正常播放。

同一冻结源码的 1.0.2（6）随后完成实体 iPad 本地数据验收：分别用前次真实接口缓存的 JSON 和保留原始时间、模式、颜色、正文的 XML 加载 7,310 条弹幕，两组真机 UI 测试通过，实际关闭后隐藏、重新开启后恢复，截图确认弹幕位于视频内且播放时间持续推进。XML 设备回读字节一致。该入口调用实际导入解析和渲染链路，但没有操作系统文件选择器，也不证明公共服务当时可用。组合版保留完整 Java runtime、动态内存预算、来源排序、片头片尾设置及播放器工具栏避让；测试运行器已卸载，验收后以普通无参数方式启动、退出 QA。详细最终验收见 [FINAL-IPADOS17.md](FINAL-IPADOS17.md)，本地回执见 `build/LocalDanmakuDeviceAcceptance/ACCEPTANCE.md` 和 `verification.json`。前一 1.0.1 在线验收的独立证据仍为 `build/danmaku-final-install.json`、`build/danmaku-final-device-playback.json`、`build/danmaku-final-device.png` 和 `build/danmaku-normal-launch.json`。

```sh
Scripts/test-danmaku-ui.sh <iPad-simulator-UUID>
```

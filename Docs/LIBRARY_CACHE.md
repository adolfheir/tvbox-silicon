# 高频追剧与本地缓存（1.0.4 / 12）

历史中的剧作为高频使用场景优先保留封面、选集信息和弹幕；在缓存达到容量上限时，先淘汰普通浏览内容，再按最近使用时间淘汰历史内容。历史页显示封面、集数和保存进度，可搜索、批量选择删除、全部清空，点击影片仍恢复到保存的时间点。

选集快照保留 6 小时，JAR/API 源续播优先使用快照，再重新解析当前播放地址；解析失败刷新详情并重试。直接文件源先刷新详情，防止沿用过期的签名视频地址。缓存不包含视频文件或视频分片。封面保留 30 天，当前集弹幕保留 7 天；当前集加载到弹幕后仅预取下一集。全部内容缓存合计限制 256 MiB，单项不超过 8 MiB。操作系统也可能回收 Caches 目录，因此缓存命中不是离线播放保证。

删除某部剧的历史会清理它的弹幕、选集、封面和片头片尾时间，删除前发起的异步下载不会重新写入缓存。官方作品/集数地址映射独立保留最近 20 部成功匹配、最长 30 天；历史删除后仍可复用这些小型索引。设置 → 高级 → 本地缓存可查看各类数量并清空全部内容缓存，同时保留播放历史、订阅、置顶源和片头片尾偏好。

片头片尾时间按「订阅 + 点播源 + 剧 ID」保存，同一部剧所有集共用，不同剧隔离；自动跳过开关仍为全局设置。旧版无法确定归属的全局时长不自动应用于每部剧，需重新为相应剧标记。点播源详情页可置顶/取消置顶，点播源列表、推荐源条及首页优先显示所选源；多个置顶源保留选择顺序。
